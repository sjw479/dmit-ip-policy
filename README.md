## IP 被墙了还是只是网络问题？先确认

先别急着提工单。连不上有时候只是本地网络抖动，不一定是 IP 进墙了。判断方法很简单：用在线端口检测工具，输入你的 VPS IP 和 SSH 端口（默认 22），看国内节点是否返回"TCP 不可达"。

DMIT 的换 IP 条件里有一条：**ICMP 和 TCP 所有端口都必须被封禁**，才算符合免费换 IP 的条件。如果只是部分端口不通、或者 ICMP（ping）还能通，按官方政策算的是"部分屏蔽"，这种情况会收费。

确认了 IP 是真被全端口封了，再往下看。

## DMIT 换 IP 政策完整拆解（Pro & EB 系列）

这是大多数中国用户买的系列，包括 Premium（三网 CN2 GIA）和 Eyeball（CMIN2）两条产品线，统称 Pro & EB。

**免费换 IP 需要同时满足下面四个条件：**

1. 这台 VPS 已经买了 7 天以上（第 8 天起才能申请）
2. 距离上一次换 IP 已经过了 15 天（包括付费换的也算）
3. ICMP 和 TCP 全端口都被封禁
4. 服务剩余有效期不少于 7 天

四个条件缺一个都不行。实际上被墙到等满 15 天再换，这段时间 VPS 基本废了，所以很多人会选择直接付 5 美元马上换，不用等。

**不符合免费条件的情况：**

随时可以提工单要换，$5/次，但两次换 IP 之间至少间隔 7 天。

还有一种情况：刚激活就发现 IP 被墙了。这个 DMIT 处理得比较人性化——**如果分配到的 IP 在实例激活时就已经被封，可以提工单免费换**，不受 15 天限制。这个权益经常被人忽视，值得记一下。

## IP Care+ 是什么？值不值得买

IP Care+ 是 DMIT 的一个付费附加服务，加了之后换 IP 的频率限制从 15 天缩短到 7 天。

说实话，这个服务对大多数人意义不大——IP 被墙频率高到每 7 天就要换一次的，说明当前 IP 段质量有问题，或者流量特征太明显，换 IP 只是治标。

如果你确实有高频换 IP 的需求（比如某些特殊业务），IP Care+ 可以考虑。普通自用梯子、IP 偶尔被墙的情况，不必特意购买。

## sPro 系列（Premium Secure）规则

sPro 是 DMIT 的高防系列，换 IP 的规则跟普通 Pro 完全不一样：

没有 IP Care+ 的情况下，换一次 IP 收费 **$15**，且两次之间最少间隔 30 天。

这个价格高不少。高防系列本来就是做站用的，IP 变来变去对建站也没什么意义，所以这个限制可以理解。

## T1（Tier 1）系列的特殊情况

T1 是 DMIT 的国际线路系列，不含专门的中国优化。这条线上的 IP 换 IP 政策有一个特别的地方：

**T1 月付新订单，DMIT 不保证分配到的 IP 在国内可用**。如果你运气不好拿到一个国内不通的 IP，换 IP 要收费 $5。

解决方法是购买 **IP Guarantee+** 附加服务（一次性 $1），买了之后如果 IP 在敏感地区（国内等）不通，可以发工单免费换一个可用的。

非月付订单（季付、年付）已经自动包含 IP Guarantee+，不用单独买。

换 IP 的收费标准是 $5/次，间隔不少于 7 天。

## FAQ

**Q：IP 被墙了但没满 15 天，只能付 $5 换吗？**

对。如果不符合免费条件，$5 随时提工单换，间隔不少于 7 天。如果是刚激活就被封，属于例外情况，可以免费换，直接发工单说明情况。

**Q：DMIT 可以换 IP 是每次换一个随机的吗？**

对，换 IP 是 DMIT 随机分配一个新的 IP 地址，不能指定要哪个 IP 段。新 IP 也不保证能用于 Netflix、ChatGPT 等特定流媒体，这点官方明确说明过。

**Q：DMIT 能添加多个 IP 吗？**

不是每个套餐都支持。目前只有洛杉矶 Pro 系列（LAX.Pro）部分套餐支持添加额外 IP，需要提工单咨询。其他系列默认只有一个 IPv4，不支持购买额外 IPv4。

**Q：换 IP 后原来的 IP 还能用吗？**

不能。换 IP 是替换当前 IP，原来那个 IP 不再归属你的账户，也无法找回。

**Q：T1 系列月付不保证 IP 可用，是不是说月付 T1 大概率 IP 不能用？**

不是说概率高，而是 DMIT 不承诺保证。实际上大多数情况分到的 IP 是可用的，但如果运气差拿到一个不通的，没有 IP Guarantee+ 就只能付费换。花 $1 买 IP Guarantee+ 的性价比很高，月付 T1 建议带上这个附加服务。
